# Agent: Migrate Existing App to Hybrid

**Purpose:** Convert traditional online-only app to offline-first

**Process:**

1. Audit current app
   - Data schema
   - User flows
   - Critical paths

2. Design sync strategy
   - What data syncs?
   - Conflict resolution per entity
   - Offline policies

3. Implement gradually
   - Add offline-first store (Zustand)
   - Add sync endpoint
   - Test with low connectivity

4. Deploy in phases
   - Pilot with 1 site
   - Roll out gradually
   - Gather feedback

**Skills:**
- All 9 skills (full migration toolkit)

**Time:** 4-6 weeks per app
